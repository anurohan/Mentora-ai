# Local Setup

1. Install Node.js 22+, Python 3.11+, and Git.
2. Copy `.env.example` to `.env` and keep secrets out of Git.
3. Run `npm install`.
4. Run `npm run verify`.

For Windows, double-click `START_MENTORA.bat`. It builds the project, starts the local server, and opens `http://localhost:4173` in your default browser. Keep the command window open while using the app.

The current foundation does not require Ollama or cloud credentials. Later phases will add documented optional services and Windows startup scripts.
