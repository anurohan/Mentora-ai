# MENTORA Product Requirements

## Vision

MENTORA is a local-first learning and productivity ecosystem for school students, university students, examination aspirants, self-learners, and lifelong learners. Its promise is: **Learn. Focus. Understand. Evolve.**

## Release principles

The first release targets a Windows laptop, works without a cloud account, preserves user ownership of local data, and exposes cloud integrations only through explicit configuration. Features that depend on hardware, permissions, or external services must report a limitation instead of fabricating success.

## Product areas

1. Identity and student profile
2. Syllabus intelligence and contextual AI tutor
3. Structured educational animation studio
4. Privacy-first focus monitor and warning system
5. Study history, calendar, analytics, and exports
6. Private document library
7. Adaptive themes with Explore and Focus modes
8. Offline-first persistence and optional cloud synchronization

## Definition of done

The detailed acceptance checklist is maintained in `TASK.md` and mapped to requirement IDs in `REQUIREMENTS_TRACEABILITY.md`. A requirement becomes `VERIFIED` only after its relevant test passes and evidence is recorded.
